Codex Web GPT 導入ガイド

ChatGPT Web を Codex のモデル一覧に追加し、必要に応じてローカルのファイルやコマンドへつなぐまでを、迷わない順番で説明します。

②ChatGPT Webモデル追加

最初に必ず読む

Codex Web GPT は非公式ツールです。 OpenAI公式製品ではありません。ChatGPTの画面変更などで動かなくなる可能性があります。

APIキーは絶対にスクリーンショット・チャット・SNSへ載せないでください。 もし表示したまま共有した場合は、そのキーを削除して作り直します。

読み上げ このマニュアルを音声で確認できます。

完成すると何ができる？

Codexのモデル選択に ChatGPT Web — Instant / Medium / High などが追加されます。MCPまで設定すると、ChatGPT WebモデルからCodexの作業環境へつなぐ構成を検証できます。

導入チェックリスト

終わった項目にチェックを入れると、この端末に保存されます。

配布元は miuuyy/codex-chatgpt-web です。GitHubの Releases を開き、最新版を確認します。

ポイント：「Tags」ではなく Releases を使います。最新版には Latest が付きます。

Windows PowerShellを開き、次のコマンドを貼り付けてEnterします。

irm https://github.com/miuuyy/codex-chatgpt-web/releases/latest/download/install-launcher.ps1 | iex

成功すると、次のような行が出ます。

Installed C:\Users\user\AppData\Local\Programs\Codex Web GPT\Codex Web GPT.exe
「DevTools listening...」は異常ではありません。 ランチャー内ブラウザーの制御待ちです。
  1. ChatGPTにサインイン：ランチャー内のChatGPTブラウザーで、自分のChatGPTアカウントにログイン。
  2. ブラウザーのスモークテスト：短い応答が正常に返るか確認。
  3. Codexにインストール：ChatGPT WebモデルをCodexのモデル一覧へ追加。

3つとも緑のチェックになったら、Codexを一度終了して起動し直します。

Codexの入力欄右下にあるモデル名をクリックします。次のような項目が出れば成功です。

  • ChatGPT Web — Instant
  • ChatGPT Web — Medium
  • ChatGPT Web — High
初回は Medium 推奨。 速さと考える量のバランスが取りやすいです。
この章は上級設定です。 APIキー・Tunnel・開発者モードを扱います。単にChatGPT Webモデルを使うだけなら、ここは飛ばせます。

5-1. TunnelとAPIキーを作る

Codex Web GPTの MCP を開き、画面の案内からOpenAI Platformへ移動します。

  • Tunnel名：Codex Native2
  • Description：任意
  • Organization：自分のPersonal
  • ChatGPT workspace：候補に出る自分のワークスペースを選択

APIキーも作成します。作成直後に1回だけ表示される秘密鍵をコピーし、Codex Web GPT内だけに貼ります。

APIキーがスクショに映ったら即削除して再発行。「あとで隠せばいい」は不可です。

5-2. ChatGPT側で開発者モードをON

ChatGPTの 設定 → セキュリティとログイン → 開発者モード をONにします。

5-3. 新しいプラグインを作成

  • 名前：Codex Native2
  • 接続：トンネル
  • 利用可能なトンネル：作成した Codex Native2
  • 認証：認証なし

警告内容を読んで「理解したうえで、続行します」にチェックし、作成します。

5-4. Codex Web GPTでランタイム検証

Codex Web GPTのMCP画面へ戻り、ランタイムを検証します。緑表示で次が確認できれば接続成功です。

  • Responses proxy is healthy
  • Tunnel runtime reports healthy and ready
  • ChatGPT connector “Codex Native2” is available

重要：MCP設定後は、古いチャットを使い回さず、Codexで新しいチャットを作ってください。

このリポジトリのファイルを3つ確認して、構成を日本語で簡潔に説明して

ローカルファイルを実際に読めれば成功です。

次に、コマンド確認：

pwd と dir を実行して、現在の作業フォルダとファイル一覧を日本語で教えて

書き込みを確認したい場合は、テスト用ファイルを作らせ、内容を読み返させます。テスト後は削除します。

「Quit Codex Web GPT before updating it」

Codex Web GPTが裏で起動中です。ランチャーを完全終了してから、同じインストールコマンドを再実行します。

「Installer exited with code 2」

既存インストールが中途半端な場合があります。Windowsの「インストールされているアプリ」から Codex Web GPT をアンインストールし、再インストールします。

モデル一覧に「ChatGPT Web」が出ない

Codex Web GPTのセットアップで3項目が緑チェックか確認し、Codexを完全終了して起動し直します。

「ローカルのリポジトリへアクセスできない」

Browser-onlyの状態です。必要ならMCP設定へ進みます。

「missing cwd in trusted Codex environment context」

MCP設定前から使っていた古いCodexチャットを再利用している可能性があります。Codexを再起動 → 対象プロジェクト → 新しいチャット でやり直します。

Temporary Chat の検証エラー

ChatGPT側のUI変更で検出が一時的にズレることがあります。TunnelやAPIキーをすぐ作り直さず、ランタイム検証を再実行し、Codex Web GPTの最新版も確認します。

ChatGPT Web — Instant

軽い確認、短い修正、スピード重視。

ChatGPT Web — Medium

普段使いの第一候補。実装・調査・レビューのバランス型。

ChatGPT Web — High

複雑な設計、難しい不具合、慎重なレビュー。

Codexネイティブモデル

Codex標準の経路を使いたいとき。用途に応じて切替。

おすすめ運用：普段は Medium、重い問題だけ High。まず小さく試してから本番リポジトリに使います。

導入完了チェック

次の3つができれば、初心者向けの導入は完了です。

  1. Codexのモデル一覧に ChatGPT Web が出る
  2. 新しいCodexチャットで回答が返る
  3. 必要ならMCPのランタイム検証が緑になる
