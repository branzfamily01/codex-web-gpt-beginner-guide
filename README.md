# Codex Web GPT 初心者向け導入ガイド

初心者が画面を見ながら進められる、GitHub Pages対応の静的HTMLマニュアルです。

## 構成

- `index.html` — 公開起点
- `styles.css` — レイアウト・スマホ対応
- `app.js` — 開閉、コピー、進捗保存、読み上げ
- `assets/` — 手順用スクリーンショット

## 主な内容

1. GitHub Releasesの確認
2. Windows PowerShellでランチャーを導入
3. Codex Web GPTの基本セットアップ
4. ChatGPT WebモデルをCodexへ追加
5. MCP / Tunnel / `Codex Native2` の設定
6. ローカルファイル・コマンドの動作確認
7. よくあるエラーと対処
8. モデルの使い分け

## GitHub Pagesで公開

1. GitHubの **Settings → Pages** を開く
2. **Deploy from a branch** を選択
3. Branchを **main**、Folderを **/(root)** にする
4. **Save** を押す

数分後に公開URLが表示されます。

> 注意: Codex Web GPT は非公式ツールです。APIキーなどの秘密情報をスクリーンショットや公開リポジトリへ入れないでください。
