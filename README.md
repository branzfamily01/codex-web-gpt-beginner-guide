# Codex Web GPT 初心者向け導入ガイド

GitHub Pagesでそのまま公開できる静的HTML構成です。

## 公開方法

1. `index.html`, `styles.css`, `app.js` をGitHubリポジトリ直下へ配置
2. GitHub Settings → Pages → Deploy from a branch → `main` / `(root)` を選択
3. 保存後、表示された公開URLを開く

※ このリポジトリ版は、配布ZIPに含まれていた画面画像を `index.html` 内へ埋め込んだ自己完結版です。

## 推奨リポジトリ名

`codex-web-gpt-beginner-guide`
